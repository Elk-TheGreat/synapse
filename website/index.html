01 / Thesis

The graph is not a picture of the program. It is the program.

No hidden code generation step. The same typed graph that you edit is resolved, ordered and executed by the engine — and feeds the debugger, the compiler and exported programs.

Connect a wire. Data moves. Break a type rule. The editor says why.

A node editor is easy to draw and hard to make real. SYNAPSE starts from the execution model and works outward: ports have types, edges are validated, independent branches run in parallel, and every node reports its inputs, output and timing.

Behind the canvas sits an asynchronous dataflow executor with cancellation, timeouts, loop limits, per-node caching and a security policy for files, processes, network and scripts.

  • 01Qt-free graph model, JSON serialisation and validation
  • 02One intermediate representation for the engine and code generation
  • 03UI runs off-thread; events stream back to the canvas

02 / Capabilities

A working environment, not a canvas demo.

F / 01

Execution engine

Dataflow ordering, parallel independent operations, async nodes, cancellation, timeouts, step and loop limits, caching and cleanup. Infinite loops cannot freeze the UI.

asyncio · worker pools · per-node timing
F / 02

Type system

Boolean, integer, float, string, bytes, array, dictionary, image, audio, video, file, object and any. Optional values, custom types and explicit conversions.

validate before a single node runs
F / 03

Visual debugger

Set a breakpoint, step, pause, inspect inputs and outputs, read live values on wires, and walk the trace node by node. Built for people who have never used a debugger.

F5 debug · F10 step · live wire values
F / 04

Functions

Select a group of nodes and extract a reusable function with typed parameters and returns. Call it across graphs; functions can call other functions.

Ctrl + Alt + F to extract
F / 05

Python where you need it

A script node with an in-app editor, data passed in and results returned. Scripts run in a separate python -I interpreter with a timeout and import allow-list.

untrusted by default
F / 06

Plugins & export

Discover, install and remove node packages with manifests and compatibility checks. Export the graph as versioned JSON or a standalone Python program from the shared IR.

ext.<plugin>.<node> · JSON · Python

04 / Debug

See the value.
Then step.

Execution highlights the active node and its incoming wires. When a node finishes, the outgoing wire carries a live value preview. History, inputs, outputs and timings stay one click away.

  • F10Step over one node; inspect what changed.
  • F6Pause a running graph without stopping it.

06 / Quickstart

From zero to a running graph.

SYNAPSE is a desktop application. Install it locally, open a template and press Ctrl + Enter.

  1. InstallPython 3.11+ and a desktop session. Qt needs a display.
  2. Choose a templateArithmetic, Loop, or a blank project.
  3. Connect and configureDrag a wire, set a parameter in the inspector.
  4. Run and inspectResults land in the console; the canvas shows the trace.
TERMINAL / BASH
$ git clone https://github.com/Elk-TheGreat/synapse.git
$ cd synapse
$ python -m venv .venv
$ source .venv/bin/activate
$ pip install -e .
$ synapse
# headless? use: xvfb-run -a synapse
